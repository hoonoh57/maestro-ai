# Rendered Performance Audio

Place high-quality rendered performance audio files here for MaestroAI playback tests.

Recommended names:

- `performance-master.mp3`
- `performance-master.wav`
- `performance-master.flac`

Browser URLs:

- `/rendered/performance-master.mp3`
- `/rendered/performance-master.wav`
- `/rendered/performance-master.flac`

This folder is the first-phase RenderCache target. In the next phase, external renderers such as FluidSynth, MuseScore CLI, JJazzLab, DAW/VST hosts, or other local render servers will write their rendered output here automatically.
